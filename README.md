#Portal Educação

O Portal Educação é uma plataforma web interativa desenvolvida para facilitar o aprendizado e a consulta rápida de conceitos fundamentais de eletroeletrônica, física e engenharia elétrica.

A aplicação apresenta uma interface organizada por módulos.

#Demonstração do Projeto

O portal conta com um menu lateral de navegação dinâmica e uma área central para leitura e estudo do conteúdo técnico, incluindo explicações e fórmulas matemáticas.

#Conteúdos Disponíveis:

Componentes Passivos Básicos

1.1 Resistores e a Lei de Ohm

1.2 Capacitores e Armazenamento de Energia

1.3 Indutores e Eletromagnetismo

Semicondutores e Componentes Ativos

2.1 Diodos e Retificação

Grandezas, Sinais e Circuitos Elétricos

3.1 Leis de Kirchhoff (LKC — Lei das Correntes e LKV — Lei das Tensões)

#Tecnologias Utilizadas

HTML5: Estruturação organizada dos módulos das páginas e conteúdos.

CSS: Estilização moderna e design escuro/claro.

JavaScript (Vanilla): Manipulação do DOM para alternância de módulos e dinamismo na navegação.

#Como Executar o Projeto

Clone o repositório: git clone https://github.com/Pedro-augusto-dev9/portal-educacao.git

Acesse a pasta do projeto: cd portal-educacao

Execute no navegador: Basta dar um duplo clique no arquivo index.html ou

Utilizar a extensão Live Server no VS Code para rodar em um servidor local.
